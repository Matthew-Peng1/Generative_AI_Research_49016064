# Generative AI Research Project - 49016064

## Project Overview
This study explores the impact of Generative AI tools, evaluating whether they are a "Boon or Bane" for research environments.

## Repository Structure
This repository is organized to ensure research reproducibility and efficient data management:
- **Literature_Review/**: Contains journal articles, conference papers, and books.
- **Quantitative_Analysis/**: Includes survey data, analysis scripts (Python), and CSV files.
- **Qualitative_Analysis/**: Stores interview transcripts, consent forms, and insight reports.
- **Drafts_and_Reports/**: Research proposals, drafts, and final project reports.

## Navigation and Contribution
- Data analysis scripts are located in the `Quantitative_Analysis` folder.
- Future collaborators should create a new branch for any modifications and submit a Pull Request for review.
- All sensitive qualitative data is managed according to UQ ethical standards.
